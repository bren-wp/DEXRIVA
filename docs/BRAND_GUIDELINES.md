**Brand mark:** original greater-than-shaped source explorer glyph with underscore. Does not incorporate old JADX or Android robot artwork.

**Typography:** UI system font (Segoe UI on Windows); monospaced font for source editor. Supports scaling 100–200% and text wrapping. The logo, splash, navigation tiles, installer assets and marketing imagery use the same colors.

**Components:** minimum 44-pixel interactive target for prominent actions where space permits; contrast and keyboard focus required. Titles use DEXRIVE; application attribution may use "by Brendigo"; website is `brendigo.com`. Do not insert code-hosting links into UI.

**Assets:** `assets/dexrive-mark.svg` (brand icon), `assets/dexrive-banner.svg`, `assets/dexrive-workspace-concept.svg`, `assets/feature-*.svg`. Illustrations are **concept visuals**; never represent them as screenshots.

**Legal:** Preserve all source rights and legally mandated attribution in LICENSE/NOTICE. The Brendigo brand notice supplements, never replaces, upstream notices.

**Quality gate:** no claim of pixel-perfect parity without side-by-side screenshots from the running builds at 1280×720 / 1920×1080 / 2560×1440 and 100% / 125% / 150% / 200% scaling.
